# Arquivo histórico (anterior à 1.0)

A Game Library foi desenvolvida por muitas iterações antes de ser consolidada como
**V1.0 — Prototype**. Essas iterações usavam uma numeração interna (1.x a 3.74.0) que **não** faz
parte da numeração oficial do produto. Os documentos abaixo foram preservados **sem edição**, para
consulta técnica:

| Arquivo | Conteúdo |
|---|---|
| [`historico-tecnico-pre-1.0.md`](historico-tecnico-pre-1.0.md) | Registro técnico completo de cada iteração (antes `AUDITORIA.md`): problemas encontrados, decisões, medições e testes. |
| [`notas-de-versao-pre-1.0.md`](notas-de-versao-pre-1.0.md) | Seções "Novidades da versão 3.20–3.74" que estavam na `DOCUMENTACAO.md`. |
| [`changelog-pre-1.0.md`](changelog-pre-1.0.md) | Changelog resumido das iterações 3.62 a 3.74. |

O estado atual do produto está no [CHANGELOG](../../CHANGELOG.md) e na
[documentação](../../DOCUMENTACAO.md). Comentários no código como `// 3.74.0: …` se referem a
essa numeração interna.
